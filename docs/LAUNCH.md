## Long videos. More moments. Local AI.

PeakCut Studio adds a dark React workspace to the open-source [PeakCut](https://github.com/haziqahmedqasmi/PeakCut) engine, with clip selection running on your computer through Ollama—without paid AI API credits.

### What you can do

- Import supported video links or upload a file.
- Generate captioned vertical highlights with hooks and titles.
- Review an AI score out of 100 and the reason behind each pick.
- Trim, edit, rerender, preview, and download clips.
- Manage creator workspaces and live clipping.
- Configure social account apps, posting queues, and creator automation.
- Open the original workspace for the complete advanced toolset.

[Explore the interface](https://peakcut-studio-chi.vercel.app/) · [Install locally](https://github.com/sasukefrontenddev/peakcut-studio#quick-start) · [Feature coverage](https://github.com/sasukefrontenddev/peakcut-studio/blob/main/FEATURE-PARITY.md)

### Before you try it

The online interface needs your local engine; it is not a shared cloud processor. Models download once and run locally. Social posting requires your own platform developer apps/permissions, and Instagram/TikTok need a secured public HTTPS connection to the engine. Actual account posting has not been activated for this installation.
